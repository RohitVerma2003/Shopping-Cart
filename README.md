# 🛒 Shopping Cart App (MERN + TypeScript)
A simple shopping cart web application built using MERN stack, TypeScript, JWT authentication, and React Context for state management.

---

## 🚀 Features
- User Authentication (Signup / Login) with JWT & HttpOnly Cookies
- Browse Items & Add to Cart
- Remove Items from Cart with instant UI update
- Fully typed using TypeScript
- Axios-based API integration
- Responsive Product Card UI

---

## 🛠 Tech Stack
- Frontend: React, TypeScript, TailwindCSS, Axios, React Router
- Backend: Node.js, Express.js, MongoDB, Mongoose, JWT, Bcrypt
- State Management: React Context + Custom Hooks
